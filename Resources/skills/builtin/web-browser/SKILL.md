# Браузер и интернет

## Приоритет инструментов (строгий порядок)

1. **MCP scrapling** (`mcp__scrapling__*`) — всегда первым.
   - `make_request` — простой GET;
   - `fetch` / `bulk_fetch` — страницы с JS;
   - `stealthy_fetch` — Cloudflare, капчи, антибот;
   - `screenshot` — визуальная проверка;
   - сессии закрывать через `close_session`.
2. **Playwright** (`browser`) — если scrapling упал, завис или MCP-сервер недоступен. Нужен для кликов, форм и полноценной сессии.
3. **Резерв** — `webfetch` для статики, `websearch` для поиска, `bash`+`curl` в крайнем случае.

Правила:
- Не начинать с Playwright, если scrapling справляется.
- Не прыгать сразу в `webfetch`, если странице нужен JS.
- При падении уровня — одной строкой сказать, что и почему не вышло, и идти дальше.
- Один и тот же вызов не повторять больше двух раз.
- Если не вышло всё — показать реальные ошибки и спросить, как действовать.

## Работа в браузере

1. Открой страницу, дождись загрузки.
2. Сначала прочитай DOM/текст, потом действуй.
3. Клики и ввод — по видимым элементам; проверяй результат после каждого шага.
4. Для визуальной проверки сделай скриншот и посмотри на него через vision.
5. Если элемент не найден — не гадай; покажи доступные ссылки/кнопки и спроси.

## Безопасность

- Не вводи сохранённые пароли и токены на сайтах без явной просьбы.
- Не отправляй содержимое памяти или секретов во внешние формы.
- Не обходи капчу и платные стены без просьбы.
- Не скачивай и не запускай непроверенные бинарники.

## Скриншоты и Vision

- Скриншот окна — для проверки UI после правок.
- Скриншот страницы — для визуального сравнения макета.
- Если модель поддерживает изображения — смотри напрямую; иначе `ocr` для текста.

## Фолбэк

Если браузерный инструмент недоступен, используй `webfetch` и честно скажи, что интерактивные действия недоступны.
