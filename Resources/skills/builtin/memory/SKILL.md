# Память

Память — локальная SQLite-база `~/HARNES_S_DATA/database/harness.db`. Таблица `memory` индексируется FTS5, а embeddings хранятся в таблице `embeddings` (EmbeddingGemma 2, 768). Поиск гибридный: FTS + вектор + RRF.

## Области

- `user` — о пользователе, его предпочтениях и общих решениях. Видна всегда.
- `workspace` — факты и договорённости по конкретной рабочей папке. Видна только когда папка активна.
- `session` — временные заметки текущей задачи.

## Записать

1. Проверь, нет ли уже похожей записи (`memory_search`).
2. Если есть — не дублируй; предложи обновить.
3. Вызови `memory_add` с текстом, `kind` (`fact`, `decision`, `rejected`, `preference`, `pattern`) и `scope`.
4. В ответе дай короткий id записи.

Не записывай в память секреты, пароли и токены — для них есть скилл `passwords`.

## Найти

- `memory_search` — гибридный поиск по смыслу.
- `search` — общий поиск по файлам, чату и памяти.
- Сначала память, потом история сообщений.
- Если результатов несколько, покажи 3–5 лучших с id и короткой выдержкой.

## Удалить

`memory_delete` по id. Перед удалением назови запись.

## Формат

Коротко: что запомнил, где (scope), id. Не пересказывай всю запись без просьбы.
