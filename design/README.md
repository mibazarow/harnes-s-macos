# design/ — макет интерфейса HARNES-S

Это **не приложение** и не код, который попадает в сборку. Это HTML-макет, чтобы
увидеть целевой внешний вид из `DESIGN_CONCEPT.md` до правок Swift.

## Что открыть

- `mockup.html` — двойной клик, откроется в браузере. Работает офлайн, без зависимостей.
- `shots/` — статичные снимки для тех, кто не будет открывать HTML.

## Что внутри макета

| Элемент | Что показывает |
|---|---|
| Тулбар | стекло: `backdrop-filter: blur(30px) saturate(190%)`, верхний блик, волосяная граница |
| Контент | сплошной фон — стекла в слое контента нет (требование HIG, §8) |
| Транскрипт | без пузырей, роль капсом `labelTertiary`, контейнер 1100 px, текст 760 px |
| Блок кода | `radius.panel`, моно 12, кнопка «Копировать» по ховеру |
| Вызовы инструментов | вертикальный зазор **1 px** (решение: 1, не 4) |
| Композер | прямоугольник `radius 10`, не капсула; чипы модели/контекста/плана |
| Палитра команд (⌘K) | **предпросмотр R34**: в приложении такого экрана ещё нет, это не задача дизайн-ТЗ |
| Подсказки слэш-команд | то, что в коде называется `CommandPalette` — список над композером, правится по §10.5 |
| Пилюли подагентов | в тулбаре, капсулы, без рамки |

## Переключатели внизу слева

- **тема** — системная / светлая / тёмная. «Системная» честно следует за
  `prefers-color-scheme` браузера; явный выбор перебивает систему в обе стороны
  (раньше этого не было: `@media` перебивал переключатель, и светлая тема не включалась);
- **прозрачность** — вкл/выкл. Выключено = имитация «Уменьшить прозрачность»:
  материалы обязаны стать сплошными. Проверка требования §8;
- **окно** — 1240 / 980 px, видно, как сжимается контейнер;
- **палитра ⌘K** — предпросмотр будущего R34 (`TASKS.md`). Не путать с `CommandPalette`
  в коде: там это подсказки слэш-команд над полем ввода.

## Чего в макете нет и не должно быть

- реального поведения агента, стриминга, вызовов инструментов;
- сайдбара с чатами (решено: один чат, без боковой панели);
- Copper-темы — макет показывает только системную палитру (синий акцент); Copper
  остаётся опцией в настройках приложения и в макете не нарисован;
- `Nordwand Mono` в интерфейсе — по умолчанию SF Pro, моно только в коде.

## Как смотреть правильно

Открыть макет, открыть рядом настоящее приложение и Finder/System Settings. Смотреть
на плотность: 13 px основной текст, строки 28 px, контролы 24 px. Если макет кажется
«крупнее» системного — это ошибка макета, а не цель.

## Пересборка снимков

```bash
node tools/shots.mjs   # если понадобится; сейчас снимки сделаны одноразовым скриптом
```
