## R6. Бюджет схем: решение отложено по замеру

51 инструмент = 5 187 токенов из 5 600 (`Tuning.schemaTokenBudget`). Запас 7%, и его
делят MCP-инструменты: `schemasTokenCost` считает `mcp__*` тоже, поэтому новый сервер
двигает число без единой строки в `ToolRegistry` (записано комментарием в тесте).

Порядок, когда прижмёт: укоротить описания → deferred-каталог для редких групп
(`schedule_*`, `skill_*`, `ocr`; механизм уже работает для MCP) → и только потом
профили по режимам. Профили конфликтуют с требованием одинакового списка инструментов
между вызовами: меняется префикс, слетает кэш. Четвёртый вариант легитимен — осознанно
поднять потолок с записью замера.

## Отложено сознательно

- **Политика подтверждений `allow / ask / deny`.** `ask` требует диалога из середины
  цикла агента: continuation в execute, событие в `AgentLoop.Event`, шит в UI.
- **Checkpoint хода.** `file_versions.turn_id`, `restoreTurn(id)`, `/undo-turn`.
- **`session_search`, hooks, песочница, параллельные подагенты.** Параллельным подагентам
  сначала нужен worktree на каждого писателя.
- **Профили инструментов** — последними и только с цифрами на руках (см. R6).
