R45 (окно контекста) закрыт 27.11.2026 по варианту B. Приоритет в
`ModelContextPreferences.resolve`: ручное число модели → устаревший флаг →
**значение строки провайдера** → таблица `known` → дефолт. Число из настроек
больше не перебивается угадайкой по подстроке имени модели; таблица остаётся
для строк, где окно не задано (0 или `ProviderModel.defaultContextWindow`).
Подпись источника для строки провайдера — «из настроек». `ProviderDirectory`
теперь считает `resolvedWindow` и `contextWindowSource`, композер берёт окно
оттуда, а источник ушёл в `.help` пилюли контекста. Строка провайдера в
списке показывает то же число, что пойдёт в запрос. Флаг ручного окна
сбрасывается при сохранении провайдера, чтобы очистка поля возвращала
поведение «из модели».

R44 (список моделей) закрыт 27.11.2026. Секция «Модели» с `Picker` убрана;
вместо неё один список моделей всех провайдеров: имя модели моно-шрифтом,

смыслу: устаревшее или пустое значение показывает модель, которая реально
пойдёт в запрос. `ModelSelection` не менялся.
